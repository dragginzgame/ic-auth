# ic-auth-wire

Bounded credential, session admission, read and logout IC Wire contracts, with optional TypeScript generation. Application hosts own endpoint installation.

This pre-1.0 library belongs to the current IC Auth contract. Stable storage and
production consumer integration remain future work. See the
[repository](https://github.com/dragginzgame/ic-auth) for design, features and
qualification evidence. Licensed under the included Toko Studios Network Licence.
